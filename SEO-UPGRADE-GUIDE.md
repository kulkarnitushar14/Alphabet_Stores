## 📤 How to Deploy

**Step 1** → Extract this ZIP

**Step 2** → Upload **ALL files** to your GitHub repo (replace everything)

**Step 3** → Wait 2-3 minutes for GitHub Pages to update

**Step 4** → Submit to Google for indexing:
1. Go to [Google Search Console](https://search.google.com/search-console)
2. Add your property: `https://www.alphabetstores.com`
3. Verify ownership (DNS or HTML file method)
4. Go to **Sitemaps** → Add sitemap → enter: `sitemap.xml`
5. Click **Submit**

**Step 5** → Submit individual URLs for fast indexing:
- Use the "URL Inspection" tool in Search Console
- Paste each main page URL → click "Request Indexing"
